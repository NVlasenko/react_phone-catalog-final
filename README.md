# Nice Gadgets

A simple online store made with React, TypeScript, and SCSS.

You can browse phones, tablets, and accessories, view product details, add products to your cart, and save your favorite items.

## Live Demo

[View the website](https://nvlasenko.github.io/react_phone-catalog-final/)

*The demo link will work after the website is published on GitHub Pages.*

## Technologies Used

- React
- TypeScript
- SCSS
- Vite
- React Router

## Getting Started

To run the project locally, clone the repository:

```bash
git clone https://github.com/NVlasenko/react_phone-catalog-final.git
cd react_phone-catalog-final
```

Install dependencies:

```bash
npm install
```

Start the project:

```bash
npm run dev
```

## Features

- Browse phones, tablets, and accessories
- View product details
- Sort products
- Choose how many products to show per page
- Add products to the shopping cart
- Add products to favorites
- Change product quantity in the cart
- Remove products from the cart
- Switch between light and dark themes
- Use the website on desktop, tablet, and mobile
